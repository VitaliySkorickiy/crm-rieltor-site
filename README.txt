Публикация сайта на GitHub Pages

1. Создайте ПУБЛИЧНЫЙ репозиторий crm-rieltor-site на github.com.
2. Загрузите в корень репозитория все файлы из этой папки:
   index.html, style.css, icon.png, screenshot.jpg,
   offer.html, privacy.html, refund.html, consent.html, disclaimer.html.
3. Откройте Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: main, folder: / (root). Нажмите Save.
6. Через 1–2 минуты сайт будет доступен:
   https://vitaliyskorickiy.github.io/crm-rieltor-site/
7. Проверьте в режиме инкогнито, что сайт открывается без входа.
8. Отправьте эту ссылку в поддержку Robokassa с просьбой заменить URL магазина.

Важно: репозиторий должен быть публичным. Исходники приложения сюда не кладите — только этот сайт.
